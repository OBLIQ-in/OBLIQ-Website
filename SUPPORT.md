# Getting Help — Obliq

Need help? Here's how to reach us.

---

## 💬 Discord (real-time chat)

**[Join the Obliq Discord →](https://discord.gg/XPC4ETU7kp)**

Drop in for quick questions, pair-debugging, or just to hang out between PRs.

| Channel | What it's for |
|---------|--------------|
| `#welcome` | Introduce yourself, say hi |
| `#help` | Ask quick technical questions |
| `#show-your-work` | Share WIPs, screenshots, progress updates |
| `#announcements` | Maintainer updates, releases, events |

---

## 💡 GitHub Discussions (long-form Q&A)

**[Open a Discussion →](https://github.com/OBLIQ-in/OBLIQ-Website/discussions)**

Use Discussions when your question or proposal deserves a longer, searchable thread:

- Design proposals & RFCs
- Architecture questions
- "How do I…" walkthroughs
- Feature brainstorms

> **Rule of thumb:** If it's a quick question → Discord. If it should be searchable for future contributors → Discussions.

---

## 🐛 GitHub Issues (bugs & feature requests)

**[Open an Issue →](https://github.com/OBLIQ-in/OBLIQ-Website/issues)**

File a GitHub Issue when you've found:

- A bug you can reproduce
- A missing feature you'd like to request
- A task from the contributor to-do board

---

## 📧 Email

For private or security-related matters:

- **General support:** support@obliq.in
- **Security vulnerabilities:** See [SECURITY.md](./SECURITY.md)
